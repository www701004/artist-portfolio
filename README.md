# 陈丹青｜个人作品集原型

打开 index.html 可浏览本地测试版。站点为纯静态 HTML/CSS/JavaScript，无需安装依赖或连接外部服务。

## 页面
- index.html：主页与精选作品
- works.html：作品档案，可按年份筛选
- work.html?id=zhiqijiao：作品详情模板；从作品卡片可打开其他作品
- about.html：艺术家陈述、实践信息与联系占位区

## 交互
作品卡片悬停反馈、滚动显现、年份筛选、点击放大作品、上一件/下一件切换和页面切换遮罩。支持触屏布局、键盘焦点与系统减少动态效果偏好。

## 资料与文案
- 图片取自 Ob 的作品集资料库/参考素材/陈丹青 油画，仅选取本地原型需要的作品图。
- 首页与关于页文案根据 Ob 中的个人艺术简介整理。
- 《齐之焦》的详情文案依据现有作品阐述整理；其他作品创作说明保留待补充，避免编造背景。
- 联系方式没有放入原型；可在确认后再添加。
- 美术风格偏向与异星访客二次元插画作为内部视觉参考，未放入作品展示。
